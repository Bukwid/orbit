# Orbiter — AI-Powered Server Management Platform

> Built for IBM Bob Dev Day Hackathon 2026 | Powered by IBM watsonx.ai | Made with IBM Bob 🤖

---

## 🎯 The Problem

Every solo developer or small team managing a Linux VPS knows this pain: you're on the go, something breaks on your server, and you need a laptop, a terminal, and muscle memory for a dozen commands just to see what's wrong. There's no elegant mobile-first solution that gives you real-time visibility into your server — and certainly none with AI that can tell you *why* something is wrong in plain English.

## 💡 The Solution

Orbiter is a cross-platform server management tool (Flutter web/mobile + lightweight Go agent) that connects to any Linux VPS and gives you:

- **Live metrics dashboard** — CPU, RAM, disk, network updating in real time
- **AI-powered log analysis** — powered by IBM watsonx.ai Granite model
- **Service management** — start, stop, restart systemd and Docker services
- **Zero-config agent** — one binary, runs instantly on any Linux server

## 🚀 Quick Start (POC Demo)

### Step 1: Run the Agent on Your Server

```bash
# Upload orbiter-agent binary to your server, then:
chmod +x ./orbiter-agent
nohup ./orbiter-agent --port 8090 --token hackathon2024 > agent.log 2>&1 &

# Verify it's running
curl http://localhost:8090/health
```

### Step 2: Run the Flutter App

```bash
cd orbiter

# Set environment variables
cp .env.example .env
# Fill in your IBM watsonx.ai credentials in .env

# Run
flutter run -d chrome
```

### Step 3: Connect and Demo

- Enter your server IP and port 8090
- Token: `hackathon2024`
- Click Connect → see live metrics
- Click "Analyze Logs with AI" → see IBM watsonx.ai response

## 🌟 IBM watsonx.ai Integration

Orbiter uses the **IBM watsonx.ai Granite-3-8b-instruct** model to:

- Analyze server log files in plain English
- Identify errors, patterns, and anomalies
- Suggest actionable fixes
- Provide security assessments

API: `POST /ml/v1/text/generation?version=2023-05-29`
Auth: IBM IAM token via API key exchange

## 🗺️ Roadmap (Beyond POC)

- **Auto-agent install** — VSCode Remote SSH-style: connecting installs the agent automatically via SFTP, no manual steps
- **Universal request monitor** — capture all incoming traffic regardless of web server (nginx, Caddy, Traefik, Apache)
- **MigrationPilot** — AI scans your server config and generates a complete migration plan to any VPS provider
- **Mobile-first** — full Android/iOS app with push alerts when CPU/RAM exceeds thresholds
- **Multi-server dashboard** — manage all your VPS instances from one screen
- **File explorer UI** — browse, edit, upload files directly from the app
- **Incident timeline** — correlate metrics, logs, and service states into a readable story
